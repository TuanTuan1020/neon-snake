# 一口接一口

暖白与薄荷绿的单机贪吃蛇，无依赖、无外部请求。

## 开始玩
下载 `index.html`，用现代浏览器打开即可，断网也能玩。
若仓库已启用 GitHub Pages，可以通过站点的 `/classic/` 路径访问。

- 经典挑战：碰墙或碰到自己结束，随橙果数量逐步提速。
- 穿墙漫游：固定速度，可以跨越边界，碰到自己仍结束。
- 橙果 +10 分，每吃 5 颗出现一颗持续 8 秒的金果，金果 +30 分。
- 方向键 / WASD、触屏滑动或屏幕方向按钮控制。空格暂停/继续，Esc 暂停。
- 切换窗口自动暂停；恢复有短暂缓冲；最高分按模式保存在本机浏览器。
- 音效默认关闭，点击 ♪ 开启。浏览器禁止存储时仍可正常游戏。
